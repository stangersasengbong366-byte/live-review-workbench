# 伪直播审核工作台

粘贴可公开访问的 MP4 或视频链接后，服务会读取真实音轨并生成中文逐字稿。页面支持：

- 视频与逐字稿时间轴同步
- 中文课堂、English 英语课堂和中英双语课堂识别
- 自动整理为每段约两句话的阅读模式
- 自定义风险词和相似话术标红
- 在线修订与审核单导出

## 公开服务限制

- 单条视频最大 600 MB、最长 120 分钟
- 同时处理 1 条，最多保留 3 条排队任务
- 仅接受可公开访问的 HTTP/HTTPS 地址
- 逐字稿缓存随托管容器重启可能清空；风险词和人工修改保存在使用者自己的浏览器
